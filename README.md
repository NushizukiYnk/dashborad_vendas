# 📊 Dashboard de Vendas com Streamlit

Aplicação desenvolvida em Python utilizando Streamlit para visualização interativa de dados de vendas.
O projeto permite explorar métricas, aplicar filtros dinâmicos e gerar diferentes tipos de gráficos para análise de desempenho.

---

## 🚀 Demonstração

* 🔗 [Acessar Dashboard](https://kennedy-projeto-dashboard-de-vendas.streamlit.app/)

---

## 📦 Tecnologias utilizadas

* Python
* Streamlit
* Pandas
* Plotly / Matplotlib (ajuste conforme você usou)

---

## 📊 Funcionalidades

* Visualização interativa de dados de vendas
* Filtros dinâmicos (por período, categoria, região, etc.)
* Gráficos variados:

  * 📈 Linha (tendência ao longo do tempo)
  * 📊 Barras (comparações)

* Atualização em tempo real conforme os filtros são aplicados

---

## 🧠 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar análise de dados e construção de dashboards interativos, facilitando a tomada de decisão a partir de dados de vendas.
